---
description: How to implement Sentry in a Next.js project
---
This workflow guides you through setting up Sentry for error tracking and performance monitoring in your Next.js application.

1. **Install Sentry via Wizard**
   Run the Sentry wizard in the root of your project. This will automatically install required dependencies and create configuration files (`sentry.client.config.ts`, `sentry.server.config.ts`, `sentry.edge.config.ts`, etc.).
   ```bash
   npx @sentry/wizard@latest -i nextjs
   ```

2. **Configure Environment Variables**
   Once the wizard completes or if you are doing it manually, ensure your `.env.local` contains your Sentry DSN (Data Source Name). The wizard typically handles this, but verify it:
   ```env
   NEXT_PUBLIC_SENTRY_DSN="your_sentry_dsn_here"
   ```

3. **Verify Sentry Initialization**
   Check the automatically generated Sentry config files in your project root:
   - `sentry.client.config.ts`
   - `sentry.server.config.ts`
   - `sentry.edge.config.ts`

4. **Test the Integration**
   Create a test API route or a test button on a page that intentionally throws an error to verify that Sentry is capturing it.
   ```tsx
   // Example test button component
   <button onClick={() => { throw new Error("Sentry Test Error"); }}>
     Test Sentry
   </button>
   ```

5. **Commit Configuration**
   Remember to commit the newly generated Sentry configuration files to your version control, but ensure your auth tokens (like `SENTRY_AUTH_TOKEN` generated by the wizard) are added to your CI/CD secrets and `.gitignore`.
